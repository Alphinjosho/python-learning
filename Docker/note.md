# Topics Learned

## 1. What is Docker?

- Docker is a platform used to develop, package, and run applications.
- It packages the application along with all its dependencies.
- It ensures the application runs the same on every machine.

---

## 2. Why Docker?

Docker solves the common problem:

> "It works on my machine."

Without Docker:
- Different Python versions
- Missing libraries
- Different operating systems
- Configuration issues

With Docker:
- Same environment everywhere
- Easy deployment
- Consistent application behavior

---

## 3. What is a Container?

A Container is an isolated environment where an application runs.

It contains:
- Application code
- Python
- Required libraries
- Dependencies
- Configuration files

Containers are lightweight and portable.

---

## 4. What is a Docker Image?

A Docker Image is a blueprint or template used to create containers.

It contains:
- Application code
- Runtime
- Dependencies
- Instructions to run the application

An Image itself does not run until a container is created from it.

---

## 5. Image vs Container

| Docker Image | Docker Container |
|--------------|------------------|
| Blueprint | Running application |
| Read-only | Running instance |
| Used to create containers | Created from an image |

---

## 6. Docker Workflow

```
Dockerfile
     │
     ▼
Build Image
     │
     ▼
Docker Image
     │
     ▼
Run
     │
     ▼
Docker Container
```

---

## 7. Benefits of Docker

- Consistent development environment
- Easy deployment
- Application isolation
- Lightweight compared to Virtual Machines
- Faster project setup
- Better collaboration among developers
